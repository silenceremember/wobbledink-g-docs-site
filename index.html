Wobbledink G-Docs

Terms and values from Google Sheets, displayed locally in Google Docs and Sheets.

Connect an existing glossary spreadsheet or the Google Drive folder containing it. The first two sheets contain term keys and definitions, and value keys and values, in columns A:B.

Use [term] and {value} markers. The extension displays matching labels and hover cards, including references inside definitions. Local display does not rewrite the stored Google Doc or replace markers in other spreadsheets.

The extension can add and remove glossary entries and repair the source spreadsheet's layout. Repair formats the first two sheets and removes columns outside A:B. These actions change the source glossary spreadsheet.

Google Sheets access is used to read and maintain the glossary. When you connect a folder, read-only Drive metadata access is used to locate its glossary spreadsheet. The extension does not request permission to edit Google Docs.
